# Skills Repo Context

A collection of agent skills (slash commands and behaviors) loaded by Claude Code and other coding agents.

## Language

**Skill**:
A folder containing a `SKILL.md` file (and optional supporting files) that teaches an agent a specific capability or workflow.
_Avoid_: command, plugin, prompt

**Bucket**:
A category folder under `skills/internal/` that groups related skills (e.g. `engineering/`, `productivity/`).
_Avoid_: category folder, group

**Internal / External**:
`skills/internal/` holds skills that live in this repo (grouped into buckets). `skills/external/` holds **vendored copies** of third-party skill repos — cloned in, `.git` stripped, a `REFERENCE.md` each recording upstream source. `SKILL.md` files do live under `external/`, but the link/list scripts and `plugin.json`/`README.md` registration cover `skills/internal/` only.
_Avoid_: reference stub, local/remote

**Trigger**:
A phrase, keyword, or context pattern described in a skill's `description` frontmatter field that causes an agent to load and apply that skill.
_Avoid_: activation phrase, keyword

**SKILL.md**:
The required entry-point file for every skill. Contains YAML frontmatter (`name`, `description`) and the skill instructions.
_Avoid_: skill file, prompt file

**plugin.json**:
The `.claude-plugin/plugin.json` file that lists all public skill paths. Used by skill installers to discover skills.
_Avoid_: manifest, config file

**Plugin**:
A full Claude Code bundle (commands + agents + hooks + skills) under `plugins/<name>/`, vendored from `anthropics/claude-plugins-official`. Larger unit than a skill; a separate lane not scanned by `grab-skills`/`link-skills`.
_Avoid_: skill, extension

**marketplace.json**:
The `.claude-plugin/marketplace.json` catalog that makes `dsh` a Claude Code marketplace, listing every `plugins/<name>/`. Generated by `scripts/gen-marketplace.sh`; never hand-edited.
_Avoid_: plugin.json, catalog file

**Auto-install (settings.json)**:
`.claude/settings.json`'s `extraKnownMarketplaces` (points at the dsh mirror) + `enabledPlugins` (every plugin@dsh) — opening a repo carrying this config auto-installs the plugin set closed-net. Generated alongside `marketplace.json`.
_Avoid_: manual install, /plugin install

**link-skills**:
The `scripts/link-skills.sh` script that symlinks each skill directory into `~/.claude/skills/` for local use.
_Avoid_: install script, setup script

## Relationships

- A **bucket** (under `skills/internal/`) holds many **skills**
- A **skill** always has exactly one **SKILL.md**
- **plugin.json** references only public internal skills (engineering, productivity, misc buckets); never `external/`
- **link-skills** / **list-skills** scan `skills/internal/` only, so `external/` vendored skills are excluded automatically
- A **plugin** (under `plugins/`) is a separate lane: listed in **marketplace.json**, auto-installed via **settings.json**, and never touched by `grab-skills`/`link-skills`/`plugin.json`
